# Pala Pack for The Choicer Voicer

Voicepacks, dubs and menu packs for [The Choicer Voicer](https://yeahmaybe.itch.io/the-choicer-voicer).

## Install

Download **[`install or update.bat`](https://github.com/Palawizard/ChoicerVoicerPalaPack/raw/main/install%20or%20update.bat)** and run it. That's all you need — no Git, no manual copying.

It offers two options:

1. **Install or Update** — adds Pala's packs to your game and keeps your own packs.
2. **Install or Update - Exact Sync** — backs up your voicepacks, dubs, etc. next to the `.bat`, then removes them and installs only Pala's packs. Use this for the multiplayer mod, which requires every player to have exactly the same packs.

Packs are installed to `%APPDATA%\YeahMaybe\ChoicerVoicer\game`.

Run the game at least once before installing, so the game folder exists.

## Manual install

Grab `ChoicerVoicerPalaPack.zip` from the [latest release](https://github.com/Palawizard/ChoicerVoicerPalaPack/releases/latest) and extract its `packs_*` folders into `%APPDATA%\YeahMaybe\ChoicerVoicer\game`.
